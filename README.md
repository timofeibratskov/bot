# 🥗 NutriBot — Телеграм-бот нутрициолог

Асинхронный Telegram-бот, который помогает следить за рационом, анализирует голосовые сообщения и фотографии еды, определяет состав БЖУ и калорий, даёт советы и ведёт персональный дневник питания.

---

## 🚀 Возможности

- 🧠 **Интеграция с OpenAI GPT-4 & Whisper**
  - Ответы на **голосовые сообщения** — бот отвечает **голосом**.
  - Обработка **фото еды** — GPT-4 Turbo с Vision определяет, что на фото, и считает **БЖУ и калории**.
- 💬 **Ответы на вопросы** — бот отвечает на любые вопросы, связанные с питанием.
- 📌 **Кнопка "Дай совет"** — GPT-4 даёт совет, что поесть.
- 📊 **Личный дневник** — бот сохраняет и обновляет информацию о ваших "ценностях" в базе данных.
- 🔒 **Фильтрация ввода** — если сообщение бессмысленное или нецензурное, бот просит повторить.

---

## 🛠️ Используемые технологии

- **Python 3.10+**
- **Aiogram** — асинхронный Telegram API
- **OpenAI API**
  - `gpt-4-vision-preview` — для анализа изображений
  - `gpt-4-1106-preview` — для ответов на вопросы
  - `whisper-1` — для распознавания речи
  - `gpt-3.5-turbo-instruct` — для валидации текстов
- **Pydantic** — валидация данных
- **PostgreSQL** — хранение данных
- **SQLAlchemy (async)** — ORM
- **gTTS** — преобразование текста в речь
- **Nest AsyncIO** — корректная работа с asyncio в REPL/Jupyter
